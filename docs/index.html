Asistente RAG, corriendo en AWS Lambda

Responde preguntas sobre el perfil profesional de Ferney Quintero y cita de donde sacó cada respuesta. Lo que esta página consulta no es un servidor cualquiera: es una función Lambda desplegada desde una imagen de contenedor, con el índice de embeddings en S3, toda la infraestructura declarada en Terraform y el despliegue automatizado con GitHub Actions.

AWS Lambda Amazon ECR Amazon S3 IAM / OIDC Terraform Docker GitHub Actions Python OpenAI

La primera pregunta es lenta, entre 8 y 13 segundos. Eso es un arranque en frío: Lambda tiene que levantar el contenedor, importar numpy y bajar el índice desde S3. Las siguientes bajan a unos 5 segundos, que son casi todos la llamada al modelo. No está roto, y ese número aparece debajo de cada respuesta para que se pueda comprobar.

El portafolio oficial está en ferney-portfolio.vercel.app, que corre el mismo motor sobre Vercel. Esta página existe para poder ver funcionando el despliegue de AWS, que antes solo se podía contar.

Código completo, incluido el Terraform y el pipeline: github.com/ferquintero2013/rag-perfil-profesional. El backend es una Function URL de Lambda y recibe POST {"question": "..."}.
